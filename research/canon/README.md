# Native Adoption Research Canon

Status: `accepted / active`

This directory is the durable authority for bomgoodbueno's native-adoption
strategy, research method, productization rules, commercial sequence, and
governance. It was distilled from the former `initial_spike` tree by decision
[`D003`](../../docs/decisions/D003-repository-research-consolidation.md).

## Authority

When repository guidance conflicts, use this order:

1. the latest accepted decision for the disputed question;
2. this research canon;
3. an approved study protocol within its declared scope;
4. the active issue specification and evidence;
5. root/package roadmaps and operating guides;
6. historical material in Git history.

Current task status has one owner: [`issues/README.md`](../../issues/README.md)
for HSD and the relevant study README for a future activated research study.

## Current program sequence

```text
Hotel Shoreline controlled proof and hackathon release
  -> AILITW Iberia access audit and 27-cell field pilot
  -> focused observational study
  -> controlled Shoreline failure analogues and interventions
  -> reproducible publication and operator handoff
  -> operator-authorized validation
  -> repeatable services and earned product capabilities
```

Hotel Shoreline is controlled demonstration evidence, not a field finding.
Public-agent observations are black-box evidence, not root-cause or intervention
evidence. Only a separately authorized operator study can support a causal claim
about an external system.

The proposed follow-up is indexed at
[`research/ailitw/studies/iberia-2026/`](../ailitw/studies/iberia-2026/README.md).
It remains pre-pilot and does not authorize public testing.
