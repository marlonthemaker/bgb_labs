# MR-0 Controlled Method POC

MR-0 is the current pre-MVP checkpoint.

## Goal

Validate whether bomgoodbueno can measure, diagnose, and improve multilingual agent capability using a controlled hotel environment.

MR-0 tests the method, not a commercial product, market demand, or broad language benchmark.

## Controlled Fixture

MR-0 uses Hotel Aurora:

- independent boutique hotel;
- Porto, Portugal;
- about 24 rooms;
- small reception team;
- multilingual guest-facing workflows;
- deterministic knowledge and fake operational tools.

Hotel Aurora is a fictional research fixture. It is not a product roadmap, customer simulator, or reason to build hotel infrastructure.

## Languages

- English (`en`)
- Spanish for Spain (`es-ES`)
- Portuguese for Portugal (`pt-PT`)

## Initial Corpus

Start with 12 semantic contracts:

- 3 atomic knowledge or request cases;
- 3 compound cases;
- 3 conditional or negative-constraint cases;
- 3 pragmatic, ambiguous, corrective, or multi-turn cases.

Each contract should have reviewed language variants without silently changing its expected meaning.

## Required Outputs

- frozen Hotel Aurora fixture;
- deterministic tool contracts;
- 12 semantic contracts;
- reviewed English, `es-ES`, and `pt-PT` variants;
- baseline run and trace records;
- deterministic and human evaluation results;
- diagnostic analysis using the six-stage lifecycle;
- one targeted intervention experiment;
- matched retest and regression check;
- MR-0 report;
- method decision records.

## Exit Criteria

MR-0 is complete only when:

- another reviewer can understand and reproduce the controlled setup;
- ground truth and language variants are reviewed;
- the baseline produces interpretable evidence;
- failures can be assigned to the earliest lifecycle stage with stated uncertainty;
- one intervention is tied to a diagnosed failure and retested under matched conditions;
- results, limitations, costs, and invalid runs are reported;
- the team records what should be preserved, changed, or rejected before a live-agent proof.

MR-0 may produce a negative result. Failure to demonstrate a useful diagnostic or intervention loop is still valid evidence if reported honestly.

## Scope Constraints

MR-0 may use static data, small schemas, local scripts, a minimal reproducible runner, and report templates.

It must not introduce generic platform frameworks, APIs, databases, dashboards, authentication, billing, customer integrations, public scraping, or hotel-product behavior.
