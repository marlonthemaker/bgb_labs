# Intelligence Graph

ID: `DOC-IG-0001`
Version: v0.2
Status: proposed

## Purpose

This domain owns the program knowledge architecture: the graph of evidence, failures, hypotheses, experiments, treatments, findings, decisions, and product implications.

## Scope

- ontology for graph entities and relationships
- traceability from observation to decision
- synthesis rules across Wild, Lab, Sandbox, Trust, and Product
- finding-to-product knowledge links

## Initial Artifacts

- `GRAPH_ONTOLOGY.md`
- `TRACEABILITY_MODEL.md`

## Source Of Truth

- Graph ontology: `GRAPH_ONTOLOGY.md`
- Traceability rules: `TRACEABILITY_MODEL.md`

## Boundary

This domain defines how knowledge connects. It does not own execution tooling, raw evidence storage, or product packaging.
