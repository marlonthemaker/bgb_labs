# Glossary

ID: `DOC-FOUND-0004`
Version: v0.1

## Core Terms

- Agentic system: a model-centered system that can plan, use tools, call services, browse, retrieve, remember, or execute multi-step tasks.
- Native adoption: successful use by a multilingual user in their own language and context, including discovery, comprehension, task completion, and calibrated trust.
- Evidence substrate: the shared data model, registry, and artifacts that connect observations, experiments, interventions, and findings.
- Wild: the observational track for realistic user journeys.
- Lab: the diagnostic track for controlled multilingual behavior and representation analysis.
- Sandbox: the intervention track for black-box adaptation.
- Black-box adaptation: an external layer that changes inputs, orchestration, routing, or outputs without modifying model weights.
- Treatment: a repeatable intervention protocol applied to a baseline system.
- Failure: a documented breakdown in adoption, task progress, trust, safety, cultural fit, or outcome quality.
- Finding: an evidence-backed claim with known scope and uncertainty.
