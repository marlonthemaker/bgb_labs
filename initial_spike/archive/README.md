# Archive

This folder preserves previous generated work, prior canon, and conversation provenance.

Archived files may contain useful ideas, but they are not current authority.

Current authority lives in `../docs/`.

## Source Map

- `canonical-v0.1/` - the earlier bomgoodbueno canonical foundation package.
- `previous-canon/` - the earlier AI Native Adoption Program structure.
- `conversations/` - generated outputs preserved in the context in which they were produced.
- `generated-output/` - reserved provenance location; currently empty.

The canonical v0.1 package and previous-canon program also appear inside their originating conversation exports. The duplicated copies are retained for provenance and are not independent validation of their contents.

## How To Use Archived Material

1. Start with the active canon in `../docs/`.
2. Use archived files to recover rationale, vocabulary, hypotheses, or designs that may have been compressed during migration.
3. Check archived guidance for conflict with current scope, sequencing, terminology, and evidence requirements.
4. Record significant extraction decisions in `../MIGRATION.md` and, when semantic, in `../decisions/`.
5. Move accepted guidance into its active canonical owner. Do not make an archived file an execution dependency.
